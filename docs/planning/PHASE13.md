### א5. בדיקת יישור עברית בתצוגת GitHub (D8) — בוצעה ואושרה
הבדיקה מחייבת דחיפה של ענף עם קובץ בדיקה קטן (כותרת עברית + SVG) ותצוגה
ב-GitHub. הדחיפה היא פעולה חיצונית, ולכן לא בוצעה. מוצע ענף נפרד
`scratch/rtl-probe`, כך ש-`docs/report` נשאר נקי.

**היקף האישורים, בנפרד לכל פעולה חיצונית:**
- **יצירת `scratch/rtl-probe` ו-commit של קובץ הבדיקה — מקומיות, ⛔ אינן
  פעולה חיצונית** ואינן דורשות אישור כפול. הן מתבצעות רק בהוראה שמזכירה
  את הצעד (CP0 נשאר עצור עד אז).
- **`git push` של הענף — פעולה חיצונית:** אישור ראשוני ואישור סופי,
  כל אחד בהודעה נפרדת.
- **מחיקת הענף המרוחק — פעולה חיצונית נפרדת:** אישור ראשוני ואישור סופי
  משלו, ⛔ לא מכוח אישור הדחיפה.

**בידוד ענף הבדיקה מ-`docs/report`.** ב-`docs/report` יש שלושה שינויים
לא שמורים (`ROADMAP.html`, `docs/planning/PHASE13.md`,
`tests/test_roadmap_render.py`). ענף בדיקה שייווצר מעץ העבודה הזה עלול לשאת
אותם, ולכן הוא ייווצר ב-**worktree נפרד**, לא בעץ העבודה הראשי:
1. **יצירה:** `git worktree add --no-track -b scratch/rtl-probe <נתיב> origin/main`
   - נקודת ההתחלה `origin/main@15479cb`, עץ נקי. ⛔ לא מ-`docs/report`.
   - `<נתיב>`: תיקיית ה-scratchpad של הסשן, מחוץ לעץ הפרויקט.
   - `--no-track` הכרחי: בלעדיו git מקשר את הענף ל-`origin/main`
     (`autoSetupMerge` בברירת מחדל).
2. **כל פקודת git של הבדיקה רצה עם `git -C <נתיב>`**, כדי שלא תיגע בעץ
   הראשי.
3. **מה ייכלל ב-commit של הבדיקה: קובץ אחד בלבד** — `rtl-probe/PROBE.md`:
   - שלוש גרסאות של אותה כותרת עברית: Markdown רגיל · `<h3 align="right">` ·
     `<div dir="rtl">` עם כותרת Markdown.
   - הפניה יחסית ל-SVG שכבר קיים ב-`main` (`docs/calibration_curve_P3.svg`).
     ⛔ אין SVG חדש, ⛔ אין קובץ אחר.
   - ללא סודות או נתונים. הענף ציבורי כל עוד הוא קיים.
4. **שער לפני הדחיפה, חובה:**
   - `git -C <נתיב> diff --name-status origin/main..scratch/rtl-probe` מציג
     שורה אחת בדיוק: `A rtl-probe/PROBE.md`.
   - `git -C <נתיב> log --oneline origin/main..scratch/rtl-probe` מציג commit
     אחד.
   - אם יש כל קובץ אחר, ⛔ אין דחיפה.
5. **הדחיפה (רק אחרי שני האישורים):**
   `git -C <נתיב> push origin scratch/rtl-probe:scratch/rtl-probe`.
   ⛔ רק refspec מפורש; ⛔ לא `--all`, ⛔ לא `main`, ⛔ לא `docs/report`.
   - CI מוגדר `on: push` ללא סינון ענפים, ולכן ירוץ על הענף. זה צפוי ולא
     פוגע.
6. **הצפייה:** `github.com/drorsh88AI/funneliq-marketing-intelligence/blob/scratch/rtl-probe/rtl-probe/PROBE.md`,
   בדפדפן, לקריאה בלבד.
7. **ניקוי מקומי** (ללא אישור כפול): `git worktree remove <נתיב>` ו-
   `git branch -D scratch/rtl-probe`. **ניקוי מרוחק** הוא פעולה חיצונית נפרדת
   בשני אישורים (ר' לעיל).

**היכן נשמרים שלושת שינויי CP0:** בעץ העבודה הראשי, על `docs/report`, לא
שמורים, כפי שהם עכשיו. יצירת ה-worktree אינה נוגעת בהם. לפני ואחרי כל שלב
מאמתים ש-`git status --short` בעץ הראשי מציג את אותם שלושה קבצים `M`, ושום
קובץ נוסף. ⛔ תוצאת הבדיקה נרשמת ב-PHASE13.md בעץ הראשי, לא בענף הבדיקה.
commit מקומי של שלושת השינויים ב-`docs/report` הוא צעד נפרד שדורש הוראה.

#### תוצאות הבדיקה (01.10.2026)
ענף `scratch/rtl-probe` (commit `7692ac4`) נדחף, והקובץ נפתח בתצוגה הציבורית
של GitHub, בדפדפן Chrome, רוחב חלון 1272, רוחב מאמר 1012 (ברירת המחדל),
ערכת נושא כהה. המדידות נעשו מה-DOM המרונדר, עם אימות בצילום מסך.

**נמדד בפועל בדף של GitHub:**

| | א: כותרת Markdown רגילה | ב: `<h3 align="right">` | ג: `<div dir="rtl">` + כותרת Markdown |
|---|---|---|---|
| כיוון הכותרת | rtl | rtl | rtl |
| יישור הכותרת | צמודה לימין (רווח 0) | צמודה לימין | צמודה לימין |
| הכיתוב העברי מתחת | צמוד לימין | צמוד לימין | צמוד לימין |
| ה-SVG נטען | כן, 576×576, בגודל מקורי | כן | כן |
| מיקום ה-SVG | שמאל (רווח ימני 436) | שמאל | שמאל |

- GitHub מוסיף בעצמו `dir="auto"` לכל כותרת ולכל פסקה. לכן כותרת שהאות
  החזקה הראשונה בה עברית מתיישרת ימינה **בלי שום HTML**. גרסאות ב' ו-ג'
  אינן מוסיפות דבר, והמעטפת `dir="rtl"` אינה משפיעה על הכותרת (היא `auto`
  בעצמה).
- קריטריון 3ב (קריאות): הגרף מוצג בגודלו המקורי, בלי הקטנה, והתוויות
  והמספרים קריאים בלי הגדלה.
- קריטריון 3א (הכותרת האנגלית שבתוך ה-SVG משנית): כותרת h3 עברית של
  20px ובמשקל 600, מול כותרת SVG באנגלית בגודל כ-15px ובמשקל רגיל. ההיררכיה
  נשמרת בגודל ובמשקל, בלי להקטין את הגרף. ⚠ ברקע כהה ה-SVG מוצג על מלבן
  לבן. זו תצוגה לא מושלמת, אבל אינה קריטריון של D8.

**הסקה בלבד — לא נמדד ב-GitHub.** שלוש הטענות הבאות מבוססות על
סימולציה מקומית בדף הטעון (שינוי ה-DOM בדפדפן) ועל תקן HTML. ה-GitHub
עצמו לא רינדר אותן, ולכן הן **אינן תוצאה שנמדדה**. מה שכן נמדד בדף החי:
הכותרות והכיתובים בשלוש הגרסאות, ה-`dir="auto"` שמופיע על הכותרות, וטעינת
ה-SVG.
- **כותרת שהתו החזק הראשון בה לטיני:** לפי תקן HTML, `dir="auto"` קובע את
  הכיוון לפי התו הראשון בעל כיווניות חזקה. בסימולציה `P3 — עקומת כיול`,
  `cumulative_profit — רווח מצטבר` ו-`SHAP — הסבר מקומי` יצאו LTR ומיושרות
  לשמאל. באותה סימולציה כותרת שפותחת בספרה, ואחריה עברית, יצאה RTL
  ומיושרת לימין, כי ספרה אינה תו חזק.
- **תו U+200F (RLM) בתחילת כותרת:** בסימולציה הפך כותרת לטינית-ראשונה ל-RTL.
  ⚠ לא נבדק שהתו שורד בצינור של GitHub ובעוגני הכותרות. **אינו עומד בכלל
  שלהלן** (ר' סעיף 2), ואינו חלופה מותרת.
- **`align="right"` על הפסקה שמכילה את התמונה:** בסימולציה הזיז את התמונה
  לימין (רווח 436 ← 0). `align` על פסקת כיתוב שרד בפועל (גרסה ב'), אך על
  פסקת תמונה לא נבדק. קוסמטי, ואינו נדרש ב-D8.
